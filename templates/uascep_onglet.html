{{ icone('importer') }} Importer des membres (Excel)

  1. Téléchargez le modèle Excel vierge (ou le modèle avec un exemple).
  2. Remplissez la feuille « Membres UASCEP » : une ligne par membre. Colonnes : {{ ENT_MEMBRES|join(', ') }}.
  3. Niveau : École, Unité pédagogique, Zone pédagogique, Circonscription scolaire ou DDEMP ; Entité : nom de l'école, de l'UP…
  4. Importez le fichier : les bureaux manquants sont créés ; une ligne déjà présente (même entité, même nom et prénoms) est mise à jour.

{{ icone('info') }} Comment renseigner le module UASCEP

  1. Ajouter un membre : choisissez le niveau (école, UP, zone, CS, DDEMP), puis l'entité dans la liste (ou saisissez son nom), remplissez nom, fonction (Président, Secrétaire général…), dates du mandat, puis « Enregistrer ». Le bureau est créé automatiquement.
  2. Cachet et signature : onglet Membres, bouton « Cachet / signature » du membre (cachet généré ou image importée, signature dessinée ou importée).
  3. Bureaux : complétez la date d'élection, l'assemblée générale et le PV ; renouvelez le bureau en fin de mandat (l'ancien est archivé).
  4. Vie du bureau : par saison, calendrier, activités et résultats, réunions, caisse, budget, matériel, puis le rapport de fin de saison.
  5. Documents : composition, PV, attestations, liste des bureaux — signés avec cachets et QR.
  6. Importer (Excel) : pour saisir beaucoup de membres d'un coup.
