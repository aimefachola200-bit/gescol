Créer le groupe en trois gestes

  1. Contacts : sur le téléphone qui administrera le groupe, ouvrez cette page et touchez « {{ icone('fiche') }} Contacts pour WhatsApp » ; ouvrez le fichier et importez les contacts (ils commencent tous par « {{ prefixe }} »).
  2. Créer le groupe : WhatsApp → ⋮ → Nouveau groupe → tapez « {{ prefixe }} » et cochez tout. WhatsApp ne propose que les personnes qui ont un compte WhatsApp : les autres sont écartées d'elles-mêmes.
  3. Lien d'invitation : dans le groupe → Infos → Inviter via un lien → Copier ; collez-le ci-dessous, puis envoyez-le aux personnes absentes du groupe ({{ icone('message') }}), un toucher par personne. Les envois sont notés.

WhatsApp n'autorise aucune application à créer un groupe ni à y ajouter quelqu'un à la place de son administrateur : ces trois gestes sont le chemin le plus court. Un groupe compte au plus 1 024 membres ; au-delà, faites un groupe par zone avec le filtre ci-dessus.
